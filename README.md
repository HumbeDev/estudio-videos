# Estudio Videos

Personal tool that uploads and schedules its author's own short educational videos to the author's own YouTube channels
using **YouTube API Services**. Developed with YouTube.

- Homepage: https://humbedev.github.io/estudio-videos/
- Privacy Policy: https://humbedev.github.io/estudio-videos/privacidad.html
- Terms of Service: https://humbedev.github.io/estudio-videos/terminos.html
- Complete upload script: [`subir-youtube.mjs`](subir-youtube.mjs) (OAuth 2.0 + `videos.insert` resumable upload with
  title, description, tags, privacy and scheduled `publishAt`, plus optional `playlistItems.insert`).
